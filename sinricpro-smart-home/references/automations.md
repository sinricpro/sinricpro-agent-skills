# Automations

`automations` lists the account's automations as stored: each has a `name`, `description`, `starters` (what triggers it), optional `condition`, and `actions` (what it does).

This skill can only read automations. To create, edit, enable, disable or delete one, the user must use the SinricPro app or portal. There is no way to run an automation on demand; to do the same thing now, send its actions with `control` or use a scene.
